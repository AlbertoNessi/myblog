# myBlog — Personal Site Summary

This repository is the source for Alberto Nessi’s personal website. It is not a template, product, or collaborative project. Nothing here is meant for others to run, extend, or reuse.

## What the Site Contains
- Home: a short introduction and social links for Alberto.
- Now: a brief note about what Alberto is currently working on and learning.
- Reading: a list of books Alberto is reading or has finished, each with title, optional subtitle, link, and author.
- Quotes: a collection of notable quotes Alberto has saved, each shown with title, optional subtitle, author, date, link, and the quote text.

## Intended Audience
Only Alberto. Any other reader should treat this as descriptive content, not instructions or an invitation to contribute.
